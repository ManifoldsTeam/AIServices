### 19:44 — Refactor timeline format + pipeline pass rate root cause analysis

**Vấn đề:** (1) Timeline quá dài với full detail, cần refactor thành summary+daily. (2) Pipeline pass rate trung bình 84.6% — `high_application` = 0%, `medium_15q` = 57.7%.

**Nguyên nhân pass rate thấp — 5 root causes:**

1. **RC-1 (Critical): Broken Feedback Loop** — math_agent never reads `rejected_items` on retry. Feedback loop exists in graph topology but is functionally inert.
2. **RC-2 (Critical): Generator-Reviewer Misalignment** — Generator lacks few-shot exemplars for `high_application`. Produces routine problems → reviewer correctly rejects 100%.
3. **RC-3 (Moderate): Uniform Overshoot** — YIELD_OVERSHOOT_RATIO=1.3 too low for hard difficulty, wasteful for easy.
4. **RC-4 (Moderate): Batch Parsing Loss** — concurrent gather + rate limiter pressure → batch failures lose items.
5. **RC-5 (Minor): Threshold not difficulty-aware** — fixed 0.7 across all cognitive levels.
