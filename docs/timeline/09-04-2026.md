### 11:00 — Performance Optimization Plan

**Vấn đề:** Thời gian xử lý pipeline quá cao, đặc biệt high_application (~21.5 phút cho 10 câu). Cần plan cải thiện có hệ thống.

**Nguyên nhân (Root Cause Analysis):**

1. **RCA-1: Sequential execution** — Tất cả bước chạy tuần tự, parse batches cũng tuần tự
2. **RCA-2: 2-phase generate+parse** — Math agent cần 2 LLM calls riêng (generation + parsing)
3. **RCA-3: Lặp work trên retry** — Supervisor + Vertex Search chạy lại mỗi iteration (không cần thiết)
4. **RCA-4: Overshoot volume cao** — high_application sinh 25-48 items/iteration, tăng thời gian mọi bước

**Hành động:** Tạo plan 3 tiers với 8 tasks:

| Tier                  | Tasks                                                                       | Target                               |
| --------------------- | --------------------------------------------------------------------------- | ------------------------------------ |
| Tier 1 (Quick Wins)   | T-OPT-1.1 Parallel parse, T-OPT-1.2 Cache search, T-OPT-1.3 Skip supervisor | high_application ≤800s, total ≤1400s |
| Tier 2 (Medium)       | T-OPT-2.1 Parse-only retry, T-OPT-2.2 JSON mode, T-OPT-2.3 Parallel gen     | high_application ≤400s, total ≤900s  |
| Tier 3 (Architecture) | T-OPT-3.1 Pre-gen pool, T-OPT-3.2 Migrate google-genai                      | request time ≤10s                    |

### 13:15 — Tier 1 Performance Optimizations

**Vấn đề:** Pipeline quá chậm do sequential parse, redundant search trên retry, và supervisor gọi lại mỗi iteration.

**Hành động:**

1. **T-OPT-1.1 — Parallel parse batches:** Đổi sequential for-loop trong `_parse_raw_content()` sang `asyncio.gather()` với `Semaphore(3)` để giới hạn concurrency.
2. **T-OPT-1.2 — Cache search on retry:** Thêm logic trong `math_agent_node()`: nếu `iteration_count > 0` và `search_context` đã có trong state → reuse, skip `retrieve_context()`.
3. **T-OPT-1.3 — Skip supervisor on retry:** Đổi `reviewer fail → supervisor` thành `reviewer fail → math_agent` trong `builder.py`. Content type đã set từ iteration đầu.
